$ pinecall limits --help
Usage: pinecall limits [options]

what the org may use in this env, what it used this month, and whose keys its
calls run on

Options:
  -h, --help  display help for command

Every limit the deployment gave the org in this env — the sandbox's, or production's with
--prod — as what is used of it. A limit with no number is no limit; 0 is a limit that refuses
everything. Minutes, messages, LLM tokens, evals and simulations are this month's and start again
on the first (UTC); the rest are what the org holds now. A bought number counts; a number
imported from the org's own carrier account never does.

The last line is whose keys a call runs on: the vendors the org brought keys for
(`pinecall providers add`), and the ones the deployment lends it. A vendor in neither refuses the
call before it starts — bring a key for it.

Examples
  $ pinecall limits
  sandbox
    minutes         12 of 30 · starts again 1 Nov
    evals           40 of 100 · starts again 1 Nov
    simulations     3, no limit
    bought numbers  0 of 0
    …
    keys            yours: anthropic · lent by the deployment: google, cartesia, deepgram
