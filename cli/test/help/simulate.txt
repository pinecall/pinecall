$ pinecall simulate --help
Usage: pinecall simulate [options]

a model plays one persona against the agent, live, and the call is scored at
hang-up

Options:
  --persona <name>         one of the agent's personas: pinecall personas lists
                           them
  --judge                  read back the call.score the log seals on, and print
                           every judge
  --turns <n>              how many turns the caller improvises before hanging
                           up (default: "15")
  --voice                  a real line: a room, and the caller in a person's
                           voice
  --listen                 the call on this machine's speakers while it happens;
                           turns --voice on
  --background-noise <dB>
  --ambience <what>
  --packet-loss <share>
  --pause <seconds>        silence before each of the caller's lines, over the
                           persona's; 0 answers at once
  --goal <text>            what the caller phones about this run, in the first
                           person, over the persona's goal and the briefing
  --llm <vendor/model>     the model that plays the caller this run; the
                           persona's when unsaid
  --tts <vendor>           the vendor the caller's voice is read by this run
  --caller-voice <id>      the caller's voice this run: pinecall voices list
                           names them
  --against <values>       the agent on these for this run: stt=, llm=, tts=,
                           voice=, language=, temperature=, end_of_turn=; again
                           for another, compared
  --repeats <n>            how many times the caller rings under each
                           configuration, 1 to 10: more than once is a
                           comparison, read as how often each got it done
  --agent <name>
  --file <agent.tsx>
  -h, --help               display help for command

A model in the gateway plays the caller: every turn improvised from the persona's goal, its style
and its own facts — there is no script. The agent is whoever holds it — your `pinecall start`, a
colleague's, production's with --prod; nothing is started here. The call lands in the log like
any other. --background-noise, --ambience and --packet-loss are spoken runs only. --llm, --tts and
--caller-voice play the caller on another model or voice for this run alone; the persona keeps its
own. One of Pinecall's personas is briefed first: the gateway gives it the one concrete thing it
phones this agent about, in the agent's own terms, and keeps its manner; --goal says it yourself,
for any persona, and nobody is briefed. The caller runs on the runtime's keys unless the org brought that vendor's; each run counts
as one simulation, and what its caller cost is kept with the call. --against runs THE AGENT on
other values for this run alone — stt=, llm=, tts=, voice=, language=, temperature=, joined by
commas, as the console's test room does; said twice or more, every configuration is placed at
once against the same caller and the table reads them best first: the judges, then the reply time,
then the cost. In the sandbox only, with a key that edits the pipeline. --repeats rings the caller
that many times under each configuration, 1 to 10, with or without --against: one call tells whether
the agent can do it, several how often it does, and the table ends with that count. A comparison
larger than the org's simulated calls at once runs whole: the calls past it wait their turn.

Examples
  $ pinecall simulate --persona hurried --listen --turns 2
  $ pinecall simulate --persona hurried --voice --tts google --caller-voice Puck
  $ pinecall simulate --persona hurried --voice --judge --against llm=groq/openai/gpt-oss-120b       --against llm=google/gemini-3.5-flash-lite --against llm=anthropic/claude-haiku-5-5,tts=deepgram
  $ pinecall simulate --persona books-a-visit --judge --repeats 5
