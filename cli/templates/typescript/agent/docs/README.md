# Documents

What this agent searches on a call, as Markdown files: one topic each (hours, prices, how to get
there). This folder is a checkout of the agent's base: `pinecall docs push` writes its files into
the base by path and keeps what the base already has, `pinecall docs pull` brings the base back
here, and `pinecall docs eval` scores how well it is found. This README is never pushed.
